## 3. 备注与剩余

- admin 口令已于 11-25 重置：`deploy/teahome-admin-reset.sh` → `AdminBootstrapRunner --reset-admin-password`（要求 ≥12 位，写审计 `admin.password.reset`），并已同步 `/opt/teahome/secrets/admin_password`（444）；脚本本身不更新该 secrets 文件，换口令后需手工覆盖。Windows 检出可能丢失执行位，调用用 `bash deploy/teahome-admin-reset.sh`。
- DNS pin 后的行为比之前更严格：同一域名若解析出任一私网地址，整体拒绝（不做“过滤后再连”的降级）。
- 管理端 CSRF 校验口径：`Origin`/`Referer` 缺失、空串、字面量 `null` 均视为“无可比对值”放行（依赖 SameSite=Strict + CSRF token）；只要带了值且与管理端地址不一致就 403。过滤器层拒绝日志会打印 `originHeader`/`refererHeader` 布尔值，便于区分“没发”和“发了但不匹配”。
- 集成测试未接入 Testcontainers：需要外部可达 PostgreSQL 与 `TEAHOME_IT_DB_URL/TEAHOME_IT_DB_USER/TEAHOME_IT_DB_PASSWORD`，见下。

```bash
# 服务器准备临时库
sudo docker exec -u postgres teahome-db psql -c "CREATE DATABASE teahome_it OWNER teahome_dev"
# 本机跑（需要 pg_hba 已放行 teahome_it / teahome_dev）
cd teahome-service
TEAHOME_IT_DB_URL=jdbc:postgresql://192.168.5.156:5432/teahome_it \
TEAHOME_IT_DB_USER=teahome_dev \
TEAHOME_IT_DB_PASSWORD=... ./mvnw -Dtest=CrawlWriteIntegrationTest test
```
