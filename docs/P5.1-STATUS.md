## 1. 交付内容

| 项 | 实现 | 位置 |
| --- | --- | --- |
| 图片 SSRF DNS pin | 改用 Apache HttpClient 5（Boot BOM 管理的 `httpclient5 5.6.5`），注入校验型 `DnsResolver`：解析一次、校验全部 A/AAAA、随后只连接已校验地址，消除“校验后重新解析”的 TOCTOU；仍禁重定向、仅 80/443、5 MiB 上限（64 KiB–16 MiB 可配）、魔数嗅探 | `api/img/ImageFetcher.java`、`pom.xml` |
| 容器出站私网阻断 | `DOCKER-USER` 末尾新增：同网段与回包 RETURN，其后对 `10/8`、`100.64/10`、`127/8`、`169.254/16`、`172.16/12`、`192.0.0/24`、`192.168/16` 从 `172.18.0.0/16` 出站 DROP；5432 放行收窄为“compose 源 + 宿主 + 目标端口 5432” | `deploy/teahome-fw.sh` |
| 管理端维护页 | `GET /admin/maintenance` 展示封面缓存/审计/会话现状；三个 POST（封面 GC、审计清理、会话清理）走 writer + sudo 双闸门，均写审计 | `admin/AdminMaintenanceController.java`、`templates/admin/maintenance.html`、`layout.html` |
| 运维任务归属修正 | 图片 GC/审计清理改由 admin 容器承担（新增挂载 `/opt/teahome/images:/data/images`）；crawler 与一次性容器置 `TEAHOME_OPS_SCHEDULED=false`；`CrawlScheduler` 增加 `teahome.crawl.enabled` 条件，避免 admin 误跑抓取 | `compose.yaml`、`application.yml`、`crawl/CrawlScheduler.java` |
| 会话定时清理 | 新增 `@Scheduled(cron="0 17 * * * *")`，每小时调用现有 `purgeExpired()`；仅 admin profile | `admin/AdminSessionService.java` |
| 抓取/写库集成测试 | `parseItems(fixture) → ItemWriter.write()` 打真实 PostgreSQL；无 `TEAHOME_IT_DB_URL` 时自动跳过 | `crawl/CrawlWriteIntegrationTest.java` |

修正的既有缺陷：此前图片 GC 只在 crawler 容器执行，而 crawler 挂的是 `/opt/teahome/data/images`（与 API 的 `/opt/teahome/images` 不是同一目录），因此只删 DB 行、删不掉文件，封面文件会持续泄漏。P5.1 把运维任务迁到挂对卷的 admin 容器。

## 3. 备注与剩余

- 维护页的浏览器手工点击未在本轮完成：`/opt/teahome/secrets/admin_password` 与实际口令已在 11-24 更换，登录返回 `bad credentials`。页面渲染、三个 POST 的 302 + 审计参数、无 sudo 时 403 已由 `AdminMaintenanceControllerTest` 覆盖；需要时用当前口令登录 `http://127.0.0.1:18081/admin/maintenance` 复核。
- DNS pin 后的行为比之前更严格：同一域名若解析出任一私网地址，整体拒绝（不做“过滤后再连”的降级）。
- 集成测试未接入 Testcontainers：需要外部可达 PostgreSQL 与 `TEAHOME_IT_DB_URL/TEAHOME_IT_DB_USER/TEAHOME_IT_DB_PASSWORD`，见下。

```bash
# 服务器准备临时库
sudo docker exec -u postgres teahome-db psql -c "CREATE DATABASE teahome_it OWNER teahome_dev"
# 本机跑（需要 pg_hba 已放行 teahome_it / teahome_dev）
cd teahome-service
TEAHOME_IT_DB_URL=jdbc:postgresql://192.168.5.156:5432/teahome_it \
TEAHOME_IT_DB_USER=teahome_dev \
TEAHOME_IT_DB_PASSWORD=... ./mvnw -Dtest=CrawlWriteIntegrationTest test
```
